# TCT Damage Viewer

หน้าดูโมเดล point cloud (Potree 1.8) พร้อมบันทึกตำแหน่งความเสียหาย

- ดูอย่างเดียว: `index.html`
- โหมดแก้ไข: `index.html?edit=1` (แก้แล้วเก็บในเบราว์เซอร์ก่อน → เมนู ไฟล์ → ดาวน์โหลด tags.json → นำไปแทนไฟล์ `tags.json` ใน repo นี้เพื่อเผยแพร่)
- ลิงก์ตรงไปยังรายการ: `index.html?tag=D-001`
- ย้ายที่เก็บโมเดล: แก้ `pointCloudUrl` ใน `config.js`
